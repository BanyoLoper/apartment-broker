## Objetivo
Crear una pagina web que sea la herramienta para un broker de departamentos

## Requerimientos
- El broker debe tener la posibilidad de agregar elementos como fotos normales, fotos 360, modelos 3D, etc.
- La pagina debe poder conectarse con API de google o bing para tener una zona cercana sin revelar la ubicacion final, pero si dar una aproximacion.
- De forma automatica (triggereada por un boton) debe de proponer elementos cercanos al departamento de amenidades, como parques, escuelas, tiendas departamentales, mercados, se pueden tomar varias APIs de google que ya tengan eso registrado. 
- El broker puede dar de alta los inmuebles y darlos de baja.
- El broker puede agregar videos y comentarios
- Revisar si hay algo extra que nos pueda servir.

## Stack
Ahora se creara con un stack de cloudflare, algo sencillo y montado rapido ya que se esta en fase de venta.
En un futuro se montaria en algo mas complejo tal vez en AWS o algo mas, hacer una propuesta de migracion cuando se pase a fase de creacion si es que se cierra la fase de venta.
